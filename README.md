# 🎵 Spotify Clone

A simple, responsive frontend clone of the Spotify Web Player user interface built using only HTML and CSS.

## 🚀 Features
* Pixel-perfect dark theme layout
* Fully responsive (works on Mobile, Tablet, and Desktop)
* Flexbox and CSS Grid structure
* Clean hover animations and UI effects

## 🛠️ Built With
* HTML5
* CSS3 (Flexbox, Grid, and Custom Variables)
